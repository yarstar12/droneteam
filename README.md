# Система обноружения людей с БПЛА и построения траетктории полета без GPS
![](https://github.com/yarstar12/droneteam/blob/main/intro.png)
> Интеллектуальная система поиска и обнаружения людей с использованием беспилотного летательного аппарата и компьютерного зрения.

## 📖 О проекте
![](https://github.com/yarstar12/droneteam/blob/main/possibility.png)
Это программно-аппаратный комплекс, предназначенный для автоматического поиска людей с помощью дрона.

Проект объединяет современные методы компьютерного зрения, построение траектории движения, определение координат объектов и передачу информации на большие расстояния.

Основные задачи системы:

- обнаружение человека в кадре;
- построение траектории движения БПЛА;
- вычисление координат обнаруженного человека;
- отображение результатов поиска;
- передача информации оператору.

---

## ✨ Возможности

### 👤 Детекция человека
![](https://github.com/yarstar12/droneteam/blob/main/Det.png)
Система автоматически обнаруживает людей на видеопотоке с камеры дрона.

Особенности:

- высокая скорость работы;
- оптимизированная нейросетевая модель;
- точность обнаружения **85%**.

---

### 🛰 Построение траектории полета

Для оценки собственного перемещения используется комбинация двух алгоритмов:

- **ORB Flow**
![](https://github.com/yarstar12/droneteam/blob/main/ORB-Flow.png)
- **Edge Flow**
![](https://github.com/yarstar12/droneteam/blob/main/Edge-Flow.png)

Такой подход позволяет компенсировать недостатки каждого метода:

- ORB хорошо работает при поворотах и крупных смещениях;
- Edge Flow стабилизирует движение на прямых участках.

В результате получается более устойчивая оценка траектории движения.

---

### 📍 Определение координат человека
![](https://github.com/yarstar12/droneteam/blob/main/Coord.png)
После обнаружения человека система вычисляет его положение относительно дрона.

Полученные координаты используются для:

- передачи оператору;
- построения карты поиска;
- последующего сопровождения цели.

---

### 🗺 Построение карты
![](https://github.com/yarstar12/droneteam/blob/main/Track.png)
Проект поддерживает:

- построение **2D-траектории**;
- построение **3D-маршрута**;
- визуализацию перемещения дрона.

---

### ⚡ Оптимизация производительности
![](https://github.com/yarstar12/droneteam/blob/main/TensorRT.png)
Для ускорения работы нейронной сети используется **TensorRT**.

**Итог:**

- увеличение скорости примерно в **2.5 раза**;
- снижение потребления памяти примерно на **40%**.

---

### 📡 Передача данных
![](https://github.com/yarstar12/droneteam/blob/main/LORa.png)
Для связи используется технология **LoRa (Long Range)**.

Передаются:

- координаты обнаруженных людей;
- ключевые точки маршрута;
- траектория полета;
- статус обнаружения.

Дальность передачи — **до 15 км**.
